# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Meu's operator configures and monitors autonomous trading agents. Crypto is the primary market, starting with Delta Exchange India and then Binance.

## Product Purpose

Manage agents, exchange connections, credentials, positions, trades and notifications in one interface. The user's vision includes agents monitoring markets while the user sleeps.

## Capabilities and Constraints

The Next.js application uses tRPC, Prisma, CCXT and shared React UI components. Existing LLM agents use execution guards, capital allocations and daily limits. Delta India supports guarded isolated perpetual entries and native brackets. Binance USD-M entries have no attached brackets. Crypto ALGO/HYBRID, market research and Telegram/Slack channels are future work; do not show them as operational.

## Brand Commitments

Name: Meu. The user requested an original monochrome logo inspired by a rounded interlocking cube reference, and an app-wide neumorphic redesign inspired by a dark portfolio dashboard. Dark mode is the default with matching light mode. The user corrected the dashboard direction to matte neumorphism with solid complementary colors, following `/tmp/codex-clipboard-AwC3sK.png`; no shiny or glowing colors.

## Evidence on Hand

User-provided reference images: `/tmp/codex-clipboard-Qg2Xfn.png` (logo), `/tmp/codex-clipboard-aGoz9y.png` (dashboard). Actual exchange and agent data comes from protected APIs. Design previews must explicitly label sample data.

## Product Principles

- Show real account state and actionable errors.
- Keep execution and risk behavior intact during design work.
- Make configuration and monitoring legible on desktop and mobile.
